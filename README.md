# Arabic Study Hub｜阿拉伯語學習整理站

一個以繁體中文整理阿拉伯語文法、مصدر 與單字的響應式靜態網站。

## 本機預覽
直接以瀏覽器開啟 `index.html` 即可。

## GitHub Pages 部署
1. 建立一個新的 GitHub Repository。
2. 上傳本資料夾內所有檔案。
3. 到 Repository 的 **Settings → Pages**。
4. 在 Build and deployment 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
6. 等待部署完成，使用 Pages 顯示的網址瀏覽。

## 專案規則
新增頁面或學習內容前，請先閱讀 `AGENTS.md`。其中定義專案目的、視覺風格、檔案結構、內容格式與 AI 修改規範。
